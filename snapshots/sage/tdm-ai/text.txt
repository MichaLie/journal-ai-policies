Non-commercial TDM You do not need a license to undertake non-commercial TDM of any content you have lawful access to or of Sage’s website. If you wish to use Sage journals content for non-commercial TDM, you should do this via the CrossRef API . If you require technical assistance, please contact [email protected] . If you are unsure whether the use is considered non-commercial or commercial, please contact [email protected] Commercial TDM Use of Sage’s website and content for commercial TDM requires a license from Sage, even if you already have lawful access to the content. If you wish to use Sage journals content for commercial TDM, you should request permission via CCC Rightfind or from [email protected] . If you require technical assistance, please contact [email protected] . Artificial Intelligence (AI) including generative AI, training of large language models, Retrieval Augmented Generation (RAG) and other uses To use Sage’s website and content for any AI uses including generative AI you will need lawful access to the content you wish to use as well as a license from Sage. If you wish to use Sage journals content for any AI uses including generative AI you should request permission from [email protected] . If you require technical assistance, please contact [email protected] .
